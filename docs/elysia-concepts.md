# Elysia concepts used in this repository

| Concept                                           | What it is for                                                                                                                                         | Where                                                                                                |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------- |
| **Plugin** (`new Elysia({ name })`)               | a reusable part of the app; `name` makes it run once even when many modules `.use()` it                                                                | every file in `src/plugins/`                                                                         |
| **Scope** (`as: 'local' \| 'scoped' \| 'global'`) | hooks apply only to their own instance by default (`local`). `scoped` lifts them one level up, to the parent. `global` applies them to every instance. | `onError({ as: 'global' })` in `error-handler.ts`, `derive({ as: 'global' })` in `request-logger.ts` |
| **Macro**                                         | a custom route option that adds hooks and types                                                                                                        | `auth`, `role('admin')`, `permission({...})` in `plugins/auth.ts`                                    |
| **resolve**                                       | adds context properties **after** validation; good for auth                                                                                            | inside the `auth` macro                                                                              |
| **derive**                                        | adds context properties **before** validation                                                                                                          | `requestId`, `log` in `request-logger.ts`                                                            |
| **decorate**                                      | a static value shared by every request (a client, a config)                                                                                            | `new Elysia().decorate('mailer', mailer)` → `({ mailer }) => …`                                      |
| **state**                                         | a mutable global `store` value, e.g. a counter                                                                                                         | `new Elysia().state('hits', 0).get('/', ({ store }) => ++store.hits)`                                |
| **guard**                                         | schema or hooks shared by a group of routes                                                                                                            | `.guard({ params: PostModel.params }, …)` in `modules/posts/index.ts`                                |
| **prefix / group**                                | path prefix                                                                                                                                            | `new Elysia({ prefix: '/api/posts' })`                                                               |
| **Reference model** (`.model()`)                  | named schema, emitted as an OpenAPI component                                                                                                          | `.model({ ErrorResponse })` in `error-handler.ts`, referenced by `errorResponses(...)`               |
| **onError**                                       | maps every error to a response                                                                                                                         | `error-handler.ts`                                                                                   |
| **onAfterResponse**                               | runs after the response is sent (logs, metrics)                                                                                                        | `request-logger.ts`                                                                                  |
| **onRequest**                                     | runs before routing, for every request (even unknown routes); always global                                                                            | `security-headers.ts`                                                                                |
| **onStart**                                       | runs when the server starts listening                                                                                                                  | `rate-limit.ts` (captures the server for client IPs)                                                 |
| **status()**                                      | return a status with a typed body                                                                                                                      | `status(201, ok(post))` in controllers                                                               |
| **detail**                                        | OpenAPI metadata per route or instance                                                                                                                 | `detail: { summary, description, tags }`                                                             |

## Rules that matter

- **Always chain** (`new Elysia().use(a).get(...)`). Calling `app.use()` on a separate statement drops the routes from the `App` type.
- **Order matters.** A hook applies only to routes registered after it (except `onRequest`).
- **Declare dependencies.** A module that uses the auth macros or the `ErrorResponse` model must `.use(authGuard)` / `.use(errorHandler)` itself, even though `app.ts` uses them too.
- **Keep handlers inline** (`({ body }) => Service.create(body)`) and never pass the whole context to a service.
